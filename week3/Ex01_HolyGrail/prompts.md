# Nhật ký Prompt - Bài 1: Holy Grail Layout
Dựa trên cấu trúc HTML5, hãy viết CSS Grid để dàn trang dạng Holy Grail kinh điển gồm 5 phần:
- Header chiếm toàn bộ chiều ngang trên cùng.
- Bên dưới gồm Sidebar trái (220px), Main content (chiếm phần còn lại), Sidebar phải (200px).
- Footer nằm dưới cùng chiếm toàn bộ chiều ngang.
- Sử dụng thuộc tính grid-template-areas để bố trí và min-height: 100vh để tràn màn hình.
