# Nhật ký Prompt - Bài 6: Admin Dashboard
Thiết kế giao diện bảng điều khiển quản trị (Admin Panel):
- Sidebar rộng 250px cố định bên trái (fixed) không bị mất khi người dùng cuộn trang.
- Vùng nội dung bên phải cuộn độc lập, phía trên dùng CSS Grid chia 4 thẻ thống kê đều nhau (repeat(4, 1fr)).
- Phía dưới là một bảng dữ liệu (Data Table) chiếm toàn bộ chiều ngang.
