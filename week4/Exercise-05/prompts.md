# Nhật ký Prompt - Bài 5: Responsive Image Gallery

- **Mục tiêu:** Dùng auto-fit để tự co giãn cột lưới ảnh.
- **Prompt:** "Tạo một lưới ảnh sử dụng CSS Grid: grid-template-columns: repeat(auto-fit, minmax(250px, 1fr)). Đảm bảo ảnh tự động xuống dòng và tự dàn đều màn hình."
- **Kiểm tra:** Xem lưới ảnh hoạt động trên các kích thước màn hình.
