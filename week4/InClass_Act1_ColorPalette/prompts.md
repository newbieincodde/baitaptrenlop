# Nhật ký Prompt - Hoạt động 1: Xây dựng Bảng mã màu thông minh (Tuần 4)

- **Mục tiêu:** Định nghĩa bảng mã màu thông minh bằng CSS Variables để tái sử dụng toàn trang.
- **Prompt:** "Hãy tạo một bộ CSS Variables tại :root bao gồm: 2 màu chủ đạo (primary/secondary), 3 mức màu xám cho text, và 1 màu nền. Sau đó áp dụng các biến này vào cấu trúc Portfolio đã làm ở tuần 3."
- **Kiểm tra:** Thay đổi giá trị màu tại :root (ví dụ chuyển --primary-color sang #dc2626) xem màu có tự động cập nhật toàn trang không.
