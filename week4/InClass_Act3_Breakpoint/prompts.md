# Nhật ký Prompt - Hoạt động 3: Responsive Breakpoint Challenge (Tuần 4)

- **Mục tiêu:** Tạo điểm ngắt responsive cho khu vực dịch vụ qua 3 thiết bị.
- **Prompt:** "Sử dụng CSS Grid và Media Queries, hãy tạo một bố cục cho class '.services-container'. Yêu cầu: Màn hình > 1024px có 4 cột, màn hình 768px - 1024px có 2 cột, và màn hình < 768px có 1 cột. Sử dụng 'gap: 20px'."
- **Kiểm tra:** Co giãn cửa sổ để thấy bố cục thay đổi 4 cột -> 2 cột -> 1 cột.
