# Nhật ký Prompt - Hoạt động 4: Design System Refactoring (Tuần 4)

- **Mục tiêu:** Chuyển đổi mã cứng thành một hệ thống quản lý bằng biến CSS.
- **Prompt:** "Hãy trích xuất tất cả các mã màu và thông số khoảng cách (margin/padding) trong đoạn code này vào các biến CSS tại :root. Sau đó, thay thế các giá trị trong code gốc bằng hàm var()."
- **Kiểm tra:** Tất cả các mã màu cứng đã được thay thế.
