# Nhật ký Prompt - Bài 3: Typing Effect

- **Mục tiêu:** Hiệu ứng máy đánh chữ bằng CSS.
- **Prompt:** "Hãy viết mã CSS tạo hiệu ứng máy đánh chữ (Typing effect) cho một thẻ h1. Chữ sẽ xuất hiện dần dần từ trái sang phải, kèm theo con trỏ nhấp nháy ở cuối dòng chữ. Không sử dụng JavaScript."
- **Kiểm tra:** Chữ chạy ra giống đánh máy.
